# luxuryRental — PHASE 27 렌탈·구매·판매 핵심 UX 개선 내역 (CHANGES.md)

## 1. 개요
PHASE 27에서는 상용 명품 커머스 플랫폼의 핵심인 상품 상세 경험, 렌탈 기간별 실시간 계산기, 정품 구매 안심 가이드, 그리고 3단계 간편 명품 위탁 프로세스를 구현하였습니다.

---

## 2. 파일별 상세 변경 사항

### 2.1 신규 컴포넌트: `ProductDetailModal.tsx`
- **렌탈 대여 기간 선택기**: 3일, 5일, 7일, 14일, 30일 옵션 버튼 제공.
- **실시간 요금 산출**: `1일 요금 * 일수`로 총 예상 요금을 실시간 계산하여 CTA 버튼 및 요금표에 반영.
- **반납 및 보증금 가이드**: 대여 일수에 따른 자동 무료 택배 수거일 계산 및 보증금 면제 안내.
- **정품 구매 안내**: 200% 정품 보증서 동봉 및 우체국 무료 안심 배송 조건 명시.
- **데모 안내 뱃지**: 실제 결제가 발생하지 않는 시뮬레이션임을 명확히 안내.

### 2.2 전역 상태: `AppContext.tsx`
- `selectedProduct: SearchProduct | null` 및 `setSelectedProduct` 상태 추가.
- 카탈로그, 검색 화면, 메인 화면 간의 유기적 모달 연동 지원.

### 2.3 상품 카탈로그: `ProductCatalog.tsx`
- 각 상품 카드에 `onClick={() => setSelectedProduct(item)}` 및 키보드 `onKeyDown` 이벤트 연결.
- 상품 클릭 시 직관적인 상세 모달 트리거.

### 2.4 상품 검색: `ShopSearch.tsx`
- 검색 결과 목록에서 상품 클릭 시 검색창을 닫고 해당 상품의 상세 모달로 즉시 연결.

### 2.5 메인 라우터: `main.tsx`
- `shop-shell` 내부에 `<ProductDetailModal />` 배치하여 슬라이드업 오버레이 렌더링.

### 2.6 내 상품 판매: `ShopSell.tsx`
- 기존 단순 토스트에서 탈피하여 **3단계 간편 위탁 신청 드로어** 구현:
  - 1단계: 위탁 품목 카테고리(가방, 지갑, 시계 등) 선택
  - 2단계: 상품 상태 등급(S급, A급, B급) 및 보증서 유무 체크
  - 3단계: 예상 위탁 시세 확인 및 시뮬레이션 접수 완료 안내
  - 언제든 '이전 단계' 및 '브랜드 변경'으로 복귀 가능한 사용자 제어권 보장.
