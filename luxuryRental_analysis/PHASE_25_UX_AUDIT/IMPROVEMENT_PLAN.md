## 2. PHASE 26: 고객용 UI 디자인 정밀 고도화 계획

### 2.1 메인 화면 (`ShopMain.tsx`)
- **헤더**: 로고와 우측 3개 액션(검색, 장바구니, 관리자) 간의 시각적 밸런스 조정, 블러 배경(`backdrop-blur-md`) 유지 및 미세 그림자 세련화.
- **3대 파스텔 카드**:
  - 카드 높이 비율을 황금비로 정돈하고 텍스트 줄바꿈 가독성 개선.
  - 마우스 호버 시 미세 리프트 효과(`hover:-translate-y-0.5 hover:shadow-sm`), 터치 시 미세 스케일 피드백(`active:scale-[0.98]`).
- **이벤트 배너**:
  - `EVENT` 뱃지 시인성 강화, 텍스트 행간 정돈, 우측 원형 아이콘 글래스 효과 강화.
- **8-Grid 아이콘 메뉴**:
  - 아이콘 배경 원형의 부드러운 음영(`shadow-2xs`), 라벨 폰트 가독성 보강.
- **가이드 한눈에 카드**:
  - 카드 테두리와 호버 상태 인터랙션 세련화.

### 2.2 상품 카탈로그 (`ProductCatalog.tsx`)
- **데모 안내 배너**:
  - 일반 텍스트에서 신뢰감 있는 캡슐형 뱃지 스타일(`inline-flex items-center gap-1.5 px-3 py-1.5 rounded-xl bg-gray-100 text-gray-600 text-xs font-medium`)로 정돈.
- **상품 카드**:
  - 이미지 컨테이너에 정교한 코너 라운딩(`rounded-2xl`) 및 은은한 내부 그림자.
  - RENT(핑크 파스텔 뱃지) vs BUY(슬레이트 블루 뱃지) 명확한 시각 구분.
  - 브랜드명(볼드 12px) - 상품명(2줄 말줄임 13px) - 가격(15px 굵은 볼드 타뷸라 폰트) 위계 정립.
  - 클릭 시 상품 상세 모달 트리거 이벤트 연동.

### 2.3 카테고리 & 브랜드 탐색 (`ShopCategory.tsx`)
- 카테고리 LNB 클릭 시 우측 콘텐츠 영역에 부드러운 페이드 전환 효과 적용.
- 서브카테고리 선택 시 활성 상태 표시 바(인디케이터) 및 선택 해제 버튼 접근성 개선.
- 브랜드 탭에서 선택된 브랜드의 상품 수 카운터 뱃지 추가.

### 2.4 검색 (`ShopSearch.tsx`)
- 검색 인풋 포커스 링 개선 및 검색어 클리어 버튼 터치 영역 44px 이상 확보.
- 로컬 스토리지/메모리 기반 "최근 검색어" 칩 리스트 추가 (개별 삭제/전체 삭제 기능).
- 0건 검색 결과 시 '검색어 초기화' 및 '인기 브랜드 바로 검색' 액션 버튼 제공.

### 2.5 로그인 & 좋아요 (`ShopLike.tsx`)
- 카카오(노랑), 애플(화이트/블랙), 네이버(초록), 페이코(빨강) 소셜 버튼 간격 및 터치감 최적화.
- 로그인 혜택 툴팁(첫 렌트 70% 할인 뱃지) 마이크로 애니메이션 강화.

### 2.6 하단 내비게이션 (`BottomNav.tsx`)
- Safe Area 하단 여백 완벽 대응 및 활성 탭 인디케이터 부드러운 전환 처리.

## 3. PHASE 27: 렌탈·구매·판매 핵심 UX 개선 계획

### 3.1 상품 상세 & 렌탈 기간 선택기 (`ProductDetailModal.tsx`)
- `AppContext.tsx`에 `selectedProduct` 및 `isDetailOpen` 상태 신설.
- **모달/바텀시트 구성**:
  - 상단: 닫기 버튼, 브랜드명, 상품명, 고유 태그(RENT/BUY)
  - 중간: 상품 상태(S급 새상품급 미사용/A급 미세사용감 등 명품 표준 가이드), 정품 인증 안내
  - **렌탈 상품 선택 시 (RENT)**:
    - 대여 기간 선택 버튼 그룹: **[3일] [5일] [7일] [14일] [30일]**
    - 기간 선택에 따른 총 예상 요금 실시간 계산기: `1일 대여료 * 선택 일수 = 총 예상 대여료`
    - 보증금(면제 안내) 및 반납일(자동 수거 택배 안내)
    - 메인 액션 버튼: **"N일 렌탈 예약하기 (데모)"**
  - **구매 상품 선택 시 (BUY)**:
    - 정품 감정서 동봉 및 안심 에스크로 결제 안내
    - 메인 액션 버튼: **"즉시 구매하기 (데모)"**
  - 공통: 하단에 `[데모 안내] 실제 결제 연동 전 시뮬레이션 인터페이스입니다.` 안내문 명시.

### 3.2 내 상품 판매 3단계 위탁 프로세스 (`ShopSell.tsx`)
- 브랜드 선택 시 바로 안내문만 뜨는 대신, **"3단계 간편 위탁 신청 드로어"** 제공:
  - 1단계: 선택 브랜드 확인 및 위탁 상품 종류(가방, 지갑, 시계 등) 선택
  - 2단계: 상품 상태 체크(정품 보증서 유무, 오염/스크래치 정도)
  - 3단계: 예상 위탁 감정가 시세 가이드 확인 및 "위탁 신청서 제출하기 (데모)"
  - 사용자에게 실제 명품 위탁 플랫폼이 어떻게 작동하는지 실감나는 경험 제공.

## 4. PHASE 28: 관리자 UI/UX 고도화 계획

### 4.1 관리자 대시보드 (`ShopAdmin.tsx`, `RecruitApp.tsx`)
- 통계 카드 3종(총 구인 요청, 진행중, 충원 완료)에 상징적인 상태 컬러 닷 및 시각적 대비 부여.
- 구인 요청 카드 내 충원 인원 현황 프로그레스 바(예: 1/2명 50%) 시각화.

### 4.2 쇼핑몰 관리
- 상품 목록 렌트/구매 탭 필터링 및 가격대별 정렬 옵션 추가.
- 신규 상품 등록 폼에 브랜드 선택 셀렉트, 렌트/구매 라디오, 일일 대여료/판매가 입력 필드 세련화.
- 로컬 메모리 상태 반영 시 성공 토스트 및 인라인 피드백 제공.

### 4.3 구인 요청 작성 폼 인체공학
- 근무 날짜 및 시간대 간편 프리셋 버튼(오전 타임, 오후 타임, 종일 타임) 제공.
- 필수 필드 미입력 시 인라인 에러 텍스트 표시 및 실시간 폼 유효성 체크.

### 4.4 근무자 DB 일괄 액션
- 전체 선택 / 전체 해제 토글 버튼.
- 선택 인원에 맞춘 동적 액션 바: "선택한 N명의 근무자에게 출근 확정 알림톡 발송 (데모)".

### 4.5 실시간 소통 (채팅)
- 읽지 않은 메시지 카운트 뱃지 표시.
- 자주 쓰는 빠른 응답 프리셋 칩("지원자 확인 완료", "금일 충원 완료", "출근 일정 조율 중") 제공.
- 메시지 입력 후 엔터키 전송 및 자동 스크롤 부드럽게 유지.

### 4.6 6개 뷰포트 반응형 안정화
- 320px(초소형 모바일), 375px, 430px(아이폰 16 Pro Max), 768px(태블릿), 1366px, 1920px(FHD 데스크톱) 완벽 대응.
