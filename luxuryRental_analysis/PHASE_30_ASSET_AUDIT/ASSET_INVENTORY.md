## 3. 핵심 리소스별 현황 분석 및 문제점

### 3.1 메인 서비스 카드 및 바로가기 이모지 (ShopMain.tsx)
- **현상**: 모바일 최상단 핵심 유입 영역(렌트하기, 구매하기, 판매하기)과 이벤트 배너, 8-Grid 바로가기 메뉴가 모두 브라우저/OS 기본 폰트 유니코드 이모지(`👗`, `👜`, `🤝`, `🎁`, `🏷️`, `⏰`, `👆`, `🤲`, `👑`, `💼`, `💌`)에 의존하고 있음.
- **문제점**:
  1. 기기 OS(iOS, Android, Windows)마다 이모지의 렌더링 스타일, 색상, 형태가 제각각으로 왜곡되어 브랜드 정체성이 훼손됨.
  2. 파스텔 톤의 세련된 카드 배경과 유니코드 이모지의 채도/스타일이 불일치하여 명품 플랫폼 특유의 고급스러운 분위기를 연출하지 못함.

### 3.2 상품 이미지 시스템 부재 (ProductCatalog.tsx, ProductDetailModal.tsx, ShopSearch.tsx)
- **현상**: 상품 데이터에 `imageUrl` 속성이 없으며, UI 상에서 `ShoppingBag` 아이콘 하나가 들어간 회색 배경 박스(`aspect-square`, `aspect-4/3`)로 일괄 처리됨.
- **문제점**:
  1. 명품 렌탈/구매를 결정하는 가장 결정적인 요소인 "시각적 매력"이 전혀 전달되지 않음.
  2. 가방, 시계, 주얼리, 의류 등 품목이 서로 다름에도 동일한 쇼핑백 아이콘만 반복되어 탐색 몰입도를 현저히 떨어뜨림.
  3. 상품 상세 모달의 상단 약 40% 면적이 텅 빈 회색 박스로 남아 시각적 허전함이 심각함.

### 3.3 관리자 상품 이미지 관리 체계 결여 (ShopAdmin.tsx)
- **현상**: 상품 등록 모달에서 브랜드, 상품명, 유형(RENT/BUY), 가격만 입력받고 있으며, 이미지 등록/미리보기 컨트롤이 전혀 없음.
- **문제점**:
  1. 관리자가 신규 상품을 등록해도 썸네일이나 상세 이미지를 지정할 수 없어 프론트엔드 비주얼 개선 효과를 실시간으로 테스트하거나 관리할 수 없음.
  2. 클라이언트 미리보기(Object URL 또는 Base64) 체계가 없어 운영 편의성이 떨어짐.

## 4. 저작권, 상표권 및 공정 표시 가이드라인

1. **상표권 오인 방지**:
   - 실제 특정 브랜드(샤넬, 에르메스 등)의 고유 로고나 모노그램 패턴을 무단 도용하거나 모조품처럼 보이게 렌더링하지 않음.
   - 제품 플레이스홀더는 형태학적으로 우아하고 중립적인 명품 실루엣(토트백, 드레스, 크로노그래프 시계, 다이아몬드 펜던트 등)으로 자체 제작함.
2. **샘플/데모 시각물 표시 준수**:
   - 실제 촬영된 정품 사진이 아닌 일러스트 플레이스홀더의 경우, "샘플 비주얼", "LUXURY SELECTION" 등의 안내 표기를 유지하여 소비자의 오인을 원천 차단함.
3. **독자적 벡터 에셋 생성**:
   - 외부 상업용 유료 라이선스 분쟁을 방지하기 위해, 모든 SVG 벡터 에셋은 프로젝트 디자인 시스템 규격(색상, 스트로크, 하이라이트)에 맞춰 100% 자체 제작 코드로 탑재함.
