# 로컬 백엔드 실행

1. `.env.example`을 참고하여 `.env`에 로컬 MySQL 연결 정보를 설정합니다.
2. `npm run db:init`으로 상품 테이블을 준비합니다. 기존 테이블과 상품을 삭제하거나 샘플 상품을 삽입하지 않습니다.
3. `npm start`로 API 서버를 시작합니다.

`GET /api/products`는 상품 배열을 반환합니다. 상품이 없으면 정상 응답 `[]`를 반환합니다. 검색 화면은 브랜드와 상품명을 기준으로 이 목록을 필터링합니다.

프런트엔드 개발 서버는 `/api` 요청을 `127.0.0.1:5000`으로 전달합니다. 배포 시에는 동일한 `/api` 경로가 백엔드로 연결되도록 호스팅 서버를 설정해야 합니다.

## 데모 상품

`npm run db:seed`는 화면 확인용 상품 12개를 등록합니다. 같은 브랜드·데모 상품명이 있으면 건너뛰며 기존 상품을 수정하지 않습니다. `[데모]` 표기를 유지하고 실제 판매 가격으로 사용하지 마세요. 렌트 가격은 1일 기준입니다.
